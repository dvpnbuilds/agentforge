# AgentForge

AgentForge is DV's local mission-control app for Hermes operations and agent run management.

## Current contents

- `server.py` - Python backend/server
- `index.html` - primary frontend shell
- `components/` - UI components and assets
- `assets/` - app images/static assets
- `start.sh` - local startup helper

## Notes

Local databases, caches, backups, and environment files are intentionally excluded from version control.
